A one-page front page summing up Monday 23 November 2026: COP31 collapses in Antalya with no climate deal, Democrats take the House with at least 258 seats, and the Russian cargo ship Sparta II burns in the Baltic — 35 verified stories across 7 regions, drawn as a newspaper front page. Every story happened or was first reported on 23 November 2026.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the shipped `entry.png` to the output directory after checking the gate rules — a whole PNG, at most 1 MiB and 1024 by 1024 pixels — and leaves it readable by every user. No network, no clock, no randomness: two runs write byte-identical files. `render.py` is the Pillow script that drew `entry.png`; re-run it to regenerate the image.
